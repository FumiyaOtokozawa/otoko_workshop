# 素材庫（library/）

外から集めた素材を、いつでも呼び出せるように保存しておく場所です。
アプリ本体（`src/`）とは切り離してあります。アプリの動きには影響しません。

| 素材     | 中身                                     | ライセンス              | 置き場所     |
| -------- | ---------------------------------------- | ----------------------- | ------------ |
| ドット絵 | 16×16 の絵 1,409,404 枚（6,194 種類）    | CC0（自由に使える）     | `pixel-art/` |
| UI部品   | Meta の Astryx。部品 174 個・テーマ 7 種 | MIT（表示を残せば自由） | `astryx/`    |

## いちばん短い使い方

ドット絵を探す（英語で探す）:

```bash
npm run pixel -- search sword --limit 5
```

ドット絵を PNG で書き出す（番号は search で出た左端の数字）:

```bash
npm run pixel -- png 3864 --scale 16 --out ./sprites
```

UI部品の一覧を見る（初回だけ `npm run library:setup` が必要）:

```bash
npm run astryx -- component --list
```

くわしくは各フォルダの README を見てください。
