# 素材の控え（archive/）

外から取ってきた素材の「控え」です。
元のサイトが非公開になったり消えたりしても、ここから全部戻せます。

## 控えに入っている物

| 素材                  | 中身                      | 大きさ                 | 元の場所     |
| --------------------- | ------------------------- | ---------------------- | ------------ |
| ドット絵              | 全 1,409,404 枚の元の ZIP | 約 260MB（3 個に分割） | Hugging Face |
| Astryx 元コード       | v0.7.11 のファイル一式    | 約 275MB（3 個に分割） | GitHub       |
| Astryx 配布パッケージ | 公開版 11 個（0.7.11）    | 約 11MB                | npm          |
| ライセンス            | 各素材の LICENSE と説明書 | 数 KB                  | 各サイト     |

- GitHub は 1 ファイル 100MB までです。そのため 90MiB ずつに分けています
- `SHA256SUMS` は、各ファイルの目印（指紋のような値）の一覧です。壊れていないかの確認に使います

## 戻し方

控えが壊れていないか確かめる:

```bash
npm run library:verify
```

全部を戻す（ドット絵の全データ ＋ Astryx の元コード）:

```bash
npm run library:restore
```

UI部品を使えるようにする（配布パッケージは控えから入る）:

```bash
npm run library:setup
```

どれもネットの元のサイトは使いません。
ただし `library:setup` は、React などの一般的な部品を npm から入れます。

## 中身が元と同じだと言える理由（読まなくてもOK）

- ドット絵: 元の ZIP をそのまま分けただけです。戻すときに目印を照合します
- Astryx 元コード: 元の v0.7.11 とファイルの木の目印が同じです（`128ab42f…`）
  - 元の版の記録（`df8a86a3…`）の中身を、親を持たない 1 つの記録として束ねています
  - 浅い履歴のままでは束から戻せないため、この形にしました。過去の変更履歴は入っていません
- 配布パッケージ: npm の公開ファイルそのものです

## 入っていない物

- Hugging Face の Parquet 形式（同じ絵と説明文の別形式。中身は ZIP と同じ）
- Astryx の 0.7.11 より前の変更履歴
- Astryx の試作版（canary 版の vega・charts）。元コードの中には入っています
