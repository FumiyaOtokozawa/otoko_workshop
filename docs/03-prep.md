# 03. 事前準備（参加者向け・前日までに）

所要 30〜45 分。**当日ここでつまずくと、その日の学びが半分になります。**
うまくいかないときは、遠慮なく運営チャンネルに画面のスクリーンショットを貼ってください。

---

## 0. 必要なもの

- macOS / Linux / Windows（Windows の方は **WSL2** 上で作業してください）
- Node.js **20 以上**（[nodejs.org](https://nodejs.org) の LTS で OK）
- git
- GitHub アカウント（このリポジトリへのアクセス権が付与されていること）
- 運営から配布される **API キー**（前日までに届きます）

---

## 1. リポジトリを取ってくる

```bash
git clone https://github.com/FumiyaOtokozawa/otoko_workshop.git
cd otoko_workshop
npm install
```

## 2. アプリが動くことを確認する

```bash
npm run dev
```

http://localhost:5173 を開いて、タスクを1件追加できたら OK です。
確認できたらターミナルで `Ctrl + C` を押して止めてください。

## 3. Claude Code を入れる

```bash
npm install -g @anthropic-ai/claude-code
```

### API キーを設定する

運営から配布されたキーを、シェルの設定ファイルに書きます。

```bash
# zsh を使っている場合（macOS のデフォルト）
echo 'export ANTHROPIC_API_KEY="配布されたキー"' >> ~/.zshrc
source ~/.zshrc

# bash の場合
echo 'export ANTHROPIC_API_KEY="配布されたキー"' >> ~/.bashrc
source ~/.bashrc
```

> **キーは絶対にリポジトリにコミットしないでください。** チャットへの貼り付けもしないでください。
> 誤って公開してしまった場合は、隠さずすぐ運営に伝えてください。すぐ失効させます（怒られません）。

設定できたか確認：

```bash
echo $ANTHROPIC_API_KEY   # キーが表示されれば OK（空なら設定できていません）
claude --version
```

## 4. 環境チェックを通す

```bash
npm run doctor
```

**すべて OK になった画面のスクリーンショットを、前日までに運営チャンネルに送ってください。**
NG が出た場合は、表示される `→` のヒントを試してからもう一度実行してください。

## 5. 動作確認（3分で終わります）

最後に、Claude Code が実際に動くことだけ確認します。

```bash
claude
```

起動したら、次のように打ってください。

```
/explain
```

リポジトリの説明が返ってきたら準備完了です。`/exit` で終了してください。

> ここで返ってきた内容は当日また使うので、**読み込まなくて大丈夫です**。
> 「動いた」ことだけ確認できれば十分です。

## よくある質問

**Q. 事前に Claude Code の使い方を予習しておくべき？**
A. 不要です。予習してこなくても差がつかないように設計しています。予習したい方は、
公式ドキュメント（https://docs.claude.com/en/docs/claude-code）を眺める程度で十分です。

**Q. AI 開発の経験がまったくないのですが大丈夫？**
A. それを前提にした内容です。プロンプトは Level 3 まで用意してあるので、コピペで進みます。

**Q. 当日、時間内に終わらなかったら？**
A. 各パートに「完成形のブランチ」を用意してあります。遅れても必ず合流できます。
終わらないことを前提に設計してあるので、心配しないでください。
