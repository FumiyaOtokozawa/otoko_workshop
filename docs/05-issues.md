# 05. 課題カタログ

このファイルの内容を、開催2週間前までに **GitHub Issue として登録**してください。
ラベル：`level-2` / `level-3` / `level-4` と `★☆☆` / `★★☆` / `★★★`。

登録の目安：**参加者数の2倍以上**の Issue を用意します（早く終わった人が次を取れるように）。

---

## バグ（Level 2 / デモ用）

### BUG-1 ★☆☆ 検索が大文字小文字を区別してしまう 〔Level 2・全員共通〕

**再現手順**

1. `npm run dev` でアプリを開く
2. タスク「API連携の設計」を追加する
3. 検索欄に `api` と小文字で入力する

**期待する挙動**：「API連携の設計」がヒットする
**実際の挙動**：ヒットしない

**やらないこと**：全角・半角の同一視、あいまい検索、ひらがな・カタカナの同一視

> 該当箇所は `src/domain/task.ts` の `filterTasks`。テストが存在しない挙動なので、
> AI にまず**失敗するテスト**を書かせるのに適しています。

---

### BUG-2 ★☆☆ 空白だけのタイトルでタスクが作れてしまう 〔講師のデモ用〕

**再現手順**

1. タイトル欄に半角スペースだけを入力して「追加」を押す
2. 空っぽに見えるタスクが一覧に増える

**期待する挙動**：空白だけのタイトルは追加できず、エラーが表示される。
また、タイトルの前後の空白は保存時に取り除かれる

**やらないこと**：文字数の上限、禁止文字のチェック

> 講師のライブデモで使います。**参加者用（BUG-1）とは別のバグ**にすることで、答えを見せずに済みます。

## 機能追加

### FEAT-1 ★☆☆ タスクに期日を設定できるようにする 〔Level 3・全員共通〕

**やりたいこと**：タスクに期日を設定し、期限切れが見て分かるようにする。

**受け入れ条件**（運営が用意する。Level 3 では参加者に書かせない）

- [ ] タスク追加時に期日（年月日）を入力できる
- [ ] 期日を入力せずにタスクを追加することもできる（今までどおり）
- [ ] 一覧に期日が表示される
- [ ] 期日が今日より前で未完了のタスクは、期限切れと分かる見た目になる
- [ ] 完了済みのタスクは、期日を過ぎていても期限切れ扱いにしない

**やらないこと**：時刻の指定、繰り返し、通知、期日での並べ替え

> **既存データとの互換性**が論点になるよう設計してあります。
> localStorage に保存済みのタスクには期日フィールドがありません。
> 参加者がこれに気づけるかどうかが、Level 3 のいちばんの見どころです。

## Level 4 用（自分で選ぶ）

Level 4 では **受け入れ条件を参加者自身に書かせます。**
ここに書いてあるのは「やりたいこと」と「やらないこと」だけです。

### ★☆☆（Level 3 がぎりぎりだった人向け）

| ID         | やりたいこと                                                             | やらないこと                           |
| ---------- | ------------------------------------------------------------------------ | -------------------------------------- |
| **FEAT-2** | 一覧を「新しい順／古い順」で並べ替えられるようにする                     | 期日順、優先度順、複数条件の並べ替え   |
| **FEAT-3** | タスクのタグをクリックすると、そのタグで絞り込まれるようにする           | 複数タグの同時指定、タグの編集         |
| **FEAT-4** | 一覧が0件のとき、「絞り込みで0件」と「そもそもタスクがない」を出し分ける | 絞り込み条件のリセットボタン           |
| **FEAT-5** | タスクの総数と完了率を、棒グラフのような進捗バーで表示する               | 期間ごとの集計、グラフライブラリの導入 |

### ★★☆（Level 3 が時間内に終わった人向け）

| ID         | やりたいこと                                                       | やらないこと                             |
| ---------- | ------------------------------------------------------------------ | ---------------------------------------- |
| **FEAT-6** | タスクに優先度（高・中・低）を設定し、高い順に並べられるようにする | 優先度の自動判定、ドラッグ＆ドロップ     |
| **FEAT-7** | 追加済みのタスクのタイトルを、後から編集できるようにする           | タグの編集、編集履歴                     |

### ★★★（余裕がある人・2つ目を取る人向け）

| ID          | やりたいこと                                                                     | やらないこと                     |

## Issue を作るときのコツ

参加者に渡す Issue で**必ず書くべきなのは「やらないこと」**です。
これがないと AI が勝手に範囲を広げ、`npm run verify` が通らなくなり、時間が溶けます。

悪い例と良い例：

|     | 例                                                                                                         |
| --- | ---------------------------------------------------------------------------------------------------------- |
| ❌  | 「検索機能を改善する」                                                                                     |
| ✅  | 「小文字で入力しても大文字のタイトルにヒットするようにする。**あいまい検索や全角半角の同一視はやらない**」 |
