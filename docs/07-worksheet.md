# 07. 観察カード

**AI が動いている時間は、見ているだけの時間ではありません。読む時間です。**

各 Level で1枚ずつ、下の3項目を埋めてください。所要1〜2分です。
メモアプリにコピーしても、印刷しても構いません。

---

## 使い方

| タイミング        | 埋める項目                     |
| ----------------- | ------------------------------ |
| AI が動き始めたら | ① AI は何を読んだか            |
| AI が答える前に   | ② 予想：どのファイルが変わる？ |
| 差分が出てきたら  | ③ 自分ならどこを直すか         |

**②は必ず AI が答える前に書いてください。** 後から書くと予想になりません。
